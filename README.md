# VANTA
Чёрно-белый музыкальный плеер (SwiftUI, iOS 16+).

## Как получить IPA
1. Залей папку в GitHub-репозиторий.
2. Вкладка **Actions → Build IPA** (запустится сам на push).
3. Скачай артефакт `Vanta-ipa` → внутри `Vanta.ipa` (без подписи).
4. Установи через Sideloadly / AltStore / TrollStore — они сами подпишут.
